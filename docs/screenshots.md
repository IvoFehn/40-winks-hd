# 40 Winks HD screenshots

[Back to the README](../README.md)

Each pair shows original N64 textures on the left and the UHD textures from the v0.1.1 Windows ZIP on the right. Both captures use the same European prototype, input replay, frame limit and 3840 × 2160 widescreen renderer. The original runs use an empty texture directory with replacements disabled. Both sides use the same crop and scale.
