# Third-party credits

The v0.2.0 preview builds on the following projects.

| Component | Purpose | Source |
| --- | --- | --- |
| 40WinksRecomp / Dreamcompiled | Game integration | [DreaXer/40WinksRecomp](https://github.com/DreaXer/40WinksRecomp) |
| N64Recomp | Ahead-of-time CPU and audio recompilation | [N64Recomp](https://github.com/N64Recomp/N64Recomp) |
| N64ModernRuntime | Operating-system, audio and save services | [DreaXer/N64ModernRuntime](https://github.com/DreaXer/N64ModernRuntime) |
| RecompFrontend | Settings and renderer integration | [DreaXer/RecompFrontend](https://github.com/DreaXer/RecompFrontend) |
| RT64 | High-resolution rendering and texture replacements | [DreaXer/rt64](https://github.com/DreaXer/rt64) |
| N64Recomp-browser | WebAssembly and WebGPU support | [n64hub/N64Recomp-browser](https://github.com/n64hub/N64Recomp-browser) |
| SDL2 | Windows, input and audio | [SDL](https://github.com/libsdl-org/SDL) |
| curl and zlib | Runtime libraries | [curl](https://github.com/curl/curl), [zlib](https://github.com/madler/zlib) |
| DirectX Shader Compiler | Windows shader compilation | [DirectXShaderCompiler](https://github.com/microsoft/DirectXShaderCompiler) |

Exact dependency commits and our patches ship under native and web. The binary downloads include third-party notices and licenses. Fonts, icons and vendored files retain their individual notices.

The older v0.1.x packages use emulator components. Their source, credits and installation instructions remain in those release tags.
